# 杜卡迪风格仪表

2026-10-15，根据用户提供的四张 Ducati 仪表参考，统一导航、速度、罗盘和连接状态的配色与字体。
目标画布为 480×480；开机动画继续使用已确认的 PANIGALE V2S 逐字渐入效果。

## 视觉规则

| 用途 | 样式 |
| --- | --- |
| 背景 | 纯黑 `#000000` |
| 主读数、导航路线、有效倾角 | 白色 `#FFFFFF` |
| 标题、分隔线、北向标记、分页选中态、表盘末段 | 红色 `#E80016` |
| 次要单位与刻度 | 中性灰，单位 `#CFCFCF`、提示 `#9B9B9B` |
| 等待 / 改道、慢行提示 | 黄色 `#FFC400` |
| 已连接 / 已到达提示 | 黄绿色 `#A6D800` |

标题和单位采用 Barlow Condensed Medium，数字采用 SemiBold Italic；
速度页主读数为 88px；导航页车速 / 倾角、短距离与航向为 56px，
较长的公里距离和速度页倾角为 32px。
字体源文件、许可及可重复生成方法见 [字体说明](../firmware/assets/fonts/README.md)。

速度页增加 0 / 40 / 80 / 120 / 160 km/h 刻度、白色进度和红色末段，刻度与读数使用相同速度范围。
末段红色用于呼应参考图样式；页面显示的是手机提供的车速，不表示发动机转速或原车红线。
倾角区域以红色细线分隔，保留 E 版车尾图、左右方向和失效状态。
导航路线进度在畅通时为白色、缓行时为黄色、拥堵时为红色。

## 已确认的导航布局

按 [确认效果图](previews/ducati-navigation-layout-approved.png) 实现五个区域：

| 区域 | 显示内容 |
| --- | --- |
| 左上 | 下一步方向箭头和到该动作的距离，较长的公里读数自动缩小以保留完整单位 |
| 右上 | 道路限速交通标志，数据缺失时隐藏 |
| 左下 | 当前车速、小型 0–160 km/h 速度表，三位读数仍保留完整显示 |
| 右下 | `LEAN`、左右倾角和参考刻度；长按重新归零 |
| 底部中央 | 一辆 E 版摩托车，随同一份倾角旋转；长按也可重新归零 |

480×480 下，摩托车后轮接地点固定在 `(240,424)`，路线、道路与建筑投影使用同一原点。
地图区域扩大到 459 行，路线进度条位于 `(24,461)`、大小 432×5，分页提示位于最下方。
倾角无效时显示 `--°`、灰色叉号和位置点，避免把数据失效表示成已扶正。
速度页保留原有的大表盘布局。

回归检查覆盖四角位置、速度更新、限速隐藏、公里单位、左右 85° 的局部重绘与完整重绘一致性，
并修复重复创建 UI 后旧定时器访问已删除控件的问题。
