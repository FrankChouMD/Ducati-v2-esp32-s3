## 接入方式

`firmware/main/CMakeLists.txt` 为本项目的 2.16 目标定义 `DUCATI_BOOT_ANIMATION`，
`app_main` 因此选择新的 LVGL 开机程序，并在 2400ms 加一个刷新周期后创建导航界面。
上游 1.75C 入口不定义此开关，仍使用原来的 MOTO GPS 启动画面和时长。

屏幕在首次纯黑帧提交后才点亮，动画由 LVGL 工作任务推进。
动画结束或画面被删除后会停止自己的定时器，不保留对已删除控件的引用。
像素素材放在常量区，运行时无需加载视频、解析 SVG 或动态生成字体。
